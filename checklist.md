# Чек-лист пассивного исследования

## До начала

- [ ] Сформулирован вопрос исследования.
- [ ] Записаны разрешённые и запрещённые действия.
- [ ] Определён временной срез.
- [ ] Понятно, какие данные нельзя сохранять.
- [ ] Создан журнал доказательств.

## Идентификация

- [ ] Подтверждено юридическое имя.
- [ ] Зафиксированы устойчивые регистрационные идентификаторы.
- [ ] Подтверждён официальный домен.
- [ ] Собраны бренды, продукты и package IDs.
- [ ] Одноимённые сущности отделены друг от друга.

## Инфраструктура

- [ ] Проверены CT-записи и сроки сертификатов.
- [ ] Проверена история DNS, если доступна.
- [ ] IP и ASN не перепутаны с владельцем приложения.
- [ ] Домены/IP проверены минимум в двух пассивных индексах.
- [ ] Для каждого баннера записан `last seen`.
- [ ] Shared hosting/CDN исключён из прямой атрибуции.
- [ ] `0 results` описан как ограниченный отрицательный результат.

## Веб и контент

- [ ] В urlscan использован поиск существующих снимков, а не новый scan.
- [ ] Проверены редиректы, title, server, IP и дата снимка.
- [ ] Проверен Wayback и отмечены смены содержания/владельца.
- [ ] Проверены публичные документы и их даты.
- [ ] Проверены репозитории и пакетные реестры.
- [ ] Найденные секреты не проверялись и не воспроизводились полностью.

## Утечки и события

- [ ] Поиск выполнен по юридическому имени, домену, бренду и идентификатору.
- [ ] Заявление отделено от подтверждённой утечки.
- [ ] Не скачивались пароли или незаконные базы.
- [ ] HIBP domain search использовался только при подтверждённом владении доменом.
- [ ] Victim blog проверен независимым источником.
- [ ] Отсутствие совпадений не выдано за доказательство отсутствия инцидента.

## Корреляция

- [ ] Каждая связь имеет источник и дату.
- [ ] Отдельно оценены свежесть и атрибуция.
- [ ] Есть независимое подтверждение сильных выводов.
- [ ] Удалены дубликаты и зависимости от одного upstream-источника.
- [ ] Факты, наблюдения, гипотезы и неизвестное разделены.

## Отчёт

- [ ] Сначала приведены доказательства, потом оценка.
- [ ] Методика разбалловки описана простым языком.
- [ ] Исторические записи не названы действующими сервисами.
- [ ] CVE не названа подтверждённой без версии и условий.
- [ ] Указаны ограничения тарифов, аккаунтов и API.
- [ ] Перечислены данные, которые изменят вывод.
- [ ] Все ссылки открываются, а локальные файлы существуют.
